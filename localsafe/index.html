An encrypted vault for passwords, bank cards, notes and documents — passports, ID cards, driving licences. No account, no cloud of ours, no tracking: the app has no internet access at all. Everything lives in one KeePass file that you own. Free, with no ads.

Use it on your computer, too

Local Safe doesn't need its own desktop app: your vault is a standard KeePass file. On Windows, macOS or Linux open it in the free KeePassXC and fill passwords in Chrome with the KeePassXC-Browser extension.

  1. Keep the vault file in a cloud folder that you also have on your computer: iCloud Drive, Google Drive, Dropbox or OneDrive.
  2. Install KeePassXC and open the same file with your master password.
  3. In KeePassXC open Tools → Settings → Browser Integration, turn it on and tick Chrome (Firefox, Edge, Brave and Vivaldi work too).
  4. Add KeePassXC-Browser to Chrome and click Connect. Logins now fill on websites while KeePassXC is unlocked.

Edit on one device at a time when you can: Local Safe merges changes made elsewhere before it saves. KeePassXC and KeePassXC-Browser are free open-source projects, not affiliated with Migisweetlab.
